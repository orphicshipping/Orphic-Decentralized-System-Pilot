# Connective-tissue readiness — design only

This note addresses the optional next-leg preparation in the 2026-10-17 work
order. It adds no executable registry, graph schema, command or permission.
The existing operation registry, host grants, Session execution records and
retained evidence remain authoritative.

A data-only profile index can project an existing operation identity, its input
and result schema identities, validity envelope, declared resource bounds,
required evidence and qualification references. Each entry should identify the
exact profile revision and source records. Reading or importing an entry must
never import a module, bind a provider or broaden an execution grant. Unknown
availability, uncertainty or qualification stays explicit.

A composition sketch should reference existing source, operation, execution,
result and verification identities. Its initial relations can describe observes,
calibrates, constrains, derives-from, validates and supersedes, following
`docs/CONSOLIDATION.md`. Each edge needs compatible units, frame, clock/time
support, representation authority and declared covariance dependencies. A graph
that can be drawn is not an admitted or executable plan.

The next implementation should lower only compatible, explicitly authorized
relationships into the current control-plane operations. It should preserve
existing refusals, correction/invalidation and replay occurrence identities.
Before implementation, choose one existing bounded profile as the acceptance
case and specify round-trip retention, incompatible-edge refusal, no dynamic
code loading, unchanged grants and dependency invalidation checks. General
sensor fusion, new kernels, OpenUSD reload and physical actuation remain later
work orders.
